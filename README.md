# 互动式学习

一个在 Codex 聊天里使用的家教 Skill。告诉它你想学什么，它会先问一道题，听你说说自己的理解，再从你卡住的地方往下讲。

## 安装

在终端运行：

```bash
git clone https://github.com/TheHighlandss/interactive-learning.git ~/.agents/skills/interactive-learning
```

在 Codex 中打开一个新聊天，输入：

> 用 $interactive-learning 带我学 DNS 和 CDN。我有十分钟，想知道网页加载慢时该先查哪里。

## 一节课怎么上

1. **摸底。** 先用自己的话回答一个小问题。你可以只写有把握的部分，也可以直接说“不知道”。
2. **讲解。** 每次围绕一个知识缺口，结合例子说明原因。你随时可以插话、要求画图或跳过熟悉的内容。
3. **练习。** 换一个场景，由你先作判断。需要时可以要一点提示，也可以直接看答案。
4. **总结。** 说“今天先到这”，就能拿到一段小结，记录哪些内容已经能独立解释、哪些值得下次再练。换聊天时可以带上这段小结。

教学规则在 [SKILL.md](SKILL.md)，可以按自己的学习习惯调整。
